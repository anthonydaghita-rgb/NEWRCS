# Right Cyber Solutions Website

Professional IT services website for Right Cyber Solutions LLC, serving Northeastern Colorado.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Features

- Responsive design with Tailwind CSS
- 15 service pages with detailed information
- 8 location pages for SEO
- Contact form and appointment booking
- Mobile-friendly navigation with dropdown menus

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Lucide React Icons
